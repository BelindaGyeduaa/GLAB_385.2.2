# Task Setup (Jupyter Notebook)

- in terminal: `python3 -m venv labenv` (mine is `python -m venv .venv`)
- to start env: `source .venv/bin/activate` (mine is `source .venv/Scripts/activate`)
- to stop env: `deactivate`
- to create/update requirements.txt: `pip freeze > requirements.txt`
- to install kernel environment `pip install ipykernel`
- to start a jupyter notebook, always select an environment first `Select Kernel`
